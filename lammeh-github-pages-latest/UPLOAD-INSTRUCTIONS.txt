ملف موقع لَمّة الجاهز لـ GitHub Pages

1. افتحي مستودع com.haya.lammeh.
2. أزيلي ملفات الموقع القديمة فقط بعد الاحتفاظ بنسخة أو استخدام Revert عند الحاجة.
3. ارفعي جميع الملفات الموجودة بجانب هذا الملف، بما فيها index.html ومجلد assets.
4. تأكدي أن الرفع يتم إلى فرع main وفي جذر المستودع.
5. انتظري اكتمال pages-build-deployment ثم حدّثي رابط الموقع.

هذا الملف خاص بالموقع، وليس مشروع Android.
